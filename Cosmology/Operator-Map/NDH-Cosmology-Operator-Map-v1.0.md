───────────────────────────────────────────────────────────────────────────────
TIER RESPONSIBILITIES
───────────────────────────────────────────────────────────────────────────────

**NDH‑CORE**  
- Holds non-dual operators  
- Maintains runtime purity  
- No expressive lineage  
- No governance logic  

Linked concept: **NDH‑CORE**

**TISD**  
- Evaluates artifacts  
- Maintains governance boundaries  
- No expressive storage  
- No runtime operators  

Linked concept: **TISD Governance**

**NDH‑Platforms**  
- Stores expressive lineage  
- Maintains expressive provenance  
- No runtime logic  
- No governance logic  

Linked concept: **NDH‑Platforms**

───────────────────────────────────────────────────────────────────────────────
ARTIFACT FLOW SUMMARY
───────────────────────────────────────────────────────────────────────────────

1. Artifact enters TISD for evaluation  
2. TISD applies Archival Protocol v4.1  
3. Artifact is classified as:
   - Expressive → NDH‑Platforms  
   - Governance → TISD  
   - Runtime → NDH‑CORE  
   - Hybrid → Retired  
4. NDH‑Platforms stores expressive artifacts with provenance  
5. NDH‑CORE executes runtime operators  
6. TISD maintains governance boundaries  

───────────────────────────────────────────────────────────────────────────────
OPERATOR SUMMARY
───────────────────────────────────────────────────────────────────────────────

If it computes → CORE  
If it governs → TISD  
If it expresses → Platforms  
If it mixes → Retired  
If it records → Platforms or TISD
