# 🧱 **5. Spine Requirements**

## **5.1 VM Requirements**
- VM 1.1 must be deployed  
- VM 2.0 criteria must be defined  
- VM must support soft‑boundary primitives  
- VM must support deterministic ISA  
- VM must support Sentinel hooks  

## **5.2 Sentinel Requirements**
- Sentinel v1.0 must be active  
- Sentinel v2.0 must be spec’d  
- Sentinel must enforce trauma‑safe pacing  
- Sentinel must enforce recursion boundaries  

## **5.3 Hyperatlas Requirements**
- routing must be deterministic  
- routing must be non‑dual  
- routing must be provenance‑safe  
- routing must be curvature‑aligned  

## **5.4 Stability/Tonal Requirements**
- curvature envelopes must be stable  
- holonomy flatteners must be deterministic  
- expressive‑stability geometry must be supported  

## **5.5 Simulation‑Suite Requirements**
- simulation must validate curvature  
- simulation must validate provenance  
- simulation must validate governance
