## **3. Provenance Hierarchy**

The suite follows a strict provenance structure:

1. **Orbital Meta‑Document** — defines the architectural rationale  
2. **Refinement Blueprint** — defines repo‑specific refinement rules  
3. **Repo‑Specific Editions** — implement the rules  
4. **Suite Index** — provides unified navigation  
5. **Commit Plan** — defines operational deployment  
6. **Governance Banner & Footer** — unify document structure  

This hierarchy ensures naming governance flows downward and interpretive feedback flows upward.
