## **1. Purpose**

The Governance Calendar defines the **annual governance cycle**, including:

- review periods  
- amendment windows  
- Codex update cycles  
- naming‑invariant audits  
- provenance‑boundary checks  
- accessibility rule evaluations  
- validator recalibration  
- automation pipeline verification  
- cross‑repo governance summits  

It ensures Orbital governance remains **living, cyclical, and stable**.

---

## **2. Annual Governance Cycle (High‑Level)**

Orbital governance follows a **four‑phase annual cycle**:

1. **Winter — Reflection & Audit**  
2. **Spring — Amendment & Refinement**  
3. **Summer — Codex Consolidation**  
4. **Autumn — Validator & Automation Recalibration**

This cycle repeats every year.

---

## **3. Detailed Governance Calendar (2026 → 2027)**

### **January — Naming Invariant Audit**  
Review naming families in the **Naming Invariant Ledger**.  
Check for drift, shape inconsistencies, rhythm violations.

### **February — Provenance Boundary Review**  
Re‑evaluate cross‑layer naming boundaries.  
Ensure NDH‑CORE, NDH‑TIDS, and Emergent remain isolated.

### **March — Accessibility & Dyslexia‑Aware Review**  
Audit rhythm stability, acronym density, cognitive ergonomics.

### **April — Governance Schema Update Window**  
Review the **Governance Schema**.  
Add new fields if needed.

### **May — Validator Recalibration**  
Update validator rules in the **Governance Validator**.  
Add new checks for naming drift or provenance violations.

### **June — Automation Pipeline Verification**  
Verify CI/CD integration per the **Governance Automation Spec**.  
Ensure merge gates are functioning.

### **July — Codex Consolidation**  
Update the **Governance Codex** with all changes from the first half of the year.

### **August — Cross‑Repo Governance Summit**  
Orbital meets with NDH‑CORE, NDH‑TIDS, and Emergent maintainers.  
Review naming families, provenance boundaries, and documentation rhythm.

### **September — Amendment Window**  
Formal amendments to the Constitution or Charter may be proposed.

### **October — Suite Infrastructure Review**  
Update the Suite Index, Manifest, Changelog, and README.

### **November — Pre‑Almanac Review**  
Prepare the next year’s Almanac.

### **December — Almanac Publication**  
Publish the annual **Governance Almanac**.
