# **3. Phenomenon Observation (FO1)**  
### *What happened?*

A governance collision occurred because:

- Pause Directive v1.0 was **overwritten** in NDH‑PLATFORMS  
- but **copies of v1.0 remained active** in five other NDH repositories  
- before v1.1 was issued  
- resulting in **ecosystem‑wide version inconsistency**

This created a **multi‑repo governance divergence**, not a simple version mismatch.

### **4.1 What actually failed**
Not architecture.  
Not invariants.

- NDH‑PLATFORMS overwrote v1.0

NDH governance requires:

- **immutable artifacts**

Overwriting v1.0 violated these principles.

# **5. Stability Geometry (FO3)**  
### *Preventing collapse and documentation recursion*

To restore stability:

- NDH‑PLATFORMS must retrieve and archive v1.0  
- v1.1 must be installed as authoritative  
- other repos must receive mirrored notices  
- mirrors must not contain full text  
- mirrors must not cross‑reference each other  
- mirrors must only reference NDH‑PLATFORMS

This prevents:

- recursive documentation loops  
- multi‑source truth  
- evaluator confusion  
- routing drift  
- infinite correction cascades

This is the NDH‑safe pattern.
