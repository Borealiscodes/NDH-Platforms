```
# Hybrid‑Manifold Audit Action Card (v1.0)
# NDH-Platforms / Hybrid-Manifolds / Decomposition / Audits

───────────────────────────────────────────────────────────────────────────────
AUDIT INITIATION
───────────────────────────────────────────────────────────────────────────────
1. Retrieve the decomposition record  
   → Use Record Index

2. Verify SURGEON-PIN and 🧷 SAFETY-PIN  
   → Required for audit validity

3. Lock cross-repo boundaries  
   → NDH-CORE, TISD, Platforms

4. Declare audit tier  
   → NDH-Platforms / TISD / Cross-Repo

───────────────────────────────────────────────────────────────────────────────
HYBRID CLASSIFICATION CHECK
───────────────────────────────────────────────────────────────────────────────
Confirm hybrid type:
- HYBRID-RUNTIME  
- HYBRID-GOVERNANCE  
- HYBRID-MIXED  

If classification is wrong → mark **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
LAYER ISOLATION CHECK
───────────────────────────────────────────────────────────────────────────────
Verify:
- Expressive layer isolated  
- Runtime layer isolated  
- Governance layer isolated  

If any layer is misidentified → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
RUNTIME EXCISION CHECK
───────────────────────────────────────────────────────────────────────────────
Confirm removal of:
- RTO  
- NDIE  
- CCI  
- RSE  
- TGM  
- Recursion envelopes  
- Continuity physics  

Routing must be:
→ NDH-CORE or Retired

If any runtime logic remains → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
GOVERNANCE EXCISION CHECK
───────────────────────────────────────────────────────────────────────────────
Confirm removal of:
- Boundaries  
- Trauma-informed rules  
- Decision trees  
- Institutional logic  

Routing must be:
→ TISD or Retired

If any governance logic remains → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
EXPRESSIVE RESIDUE PURITY CHECK
───────────────────────────────────────────────────────────────────────────────
Residue must be:
- Expressive-only  
- Free of runtime  
- Free of governance  
- Free of hybrid remnants  

If contamination detected →  
→ Trigger Contamination Alert

───────────────────────────────────────────────────────────────────────────────
PROVENANCE CHAIN CHECK
───────────────────────────────────────────────────────────────────────────────
Verify provenance includes:
- Origin case study  
- Lineage reference  
- TISD evaluation  
- Decomposition note  
- Placement rationale  
- Cosmology alignment  
- Stability context  

If provenance incomplete → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
RESIDUE PLACEMENT CHECK
───────────────────────────────────────────────────────────────────────────────
Residue must be placed in:
→ NDH-Platforms / Emergent  
or  
→ NDH-Platforms / Archive  

If placed elsewhere → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
RETIREMENT CHECK
───────────────────────────────────────────────────────────────────────────────
Hybrid artifact must be:
→ Marked RETIRED  
→ Not present in any active tier  

If hybrid remains active → **Audit FAIL**.

───────────────────────────────────────────────────────────────────────────────
AUDIT OUTCOME
───────────────────────────────────────────────────────────────────────────────
Audit Result:
- PASS  
- CONDITIONAL PASS (corrections required)  
- FAIL
```
