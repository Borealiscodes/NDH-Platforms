# **NDH Trans‑Orbital Traversal Layer v1.0**  
### *Core movement protocol inside the NDH Safety Envelope*

---

## **1 — Purpose**
The Trans‑Orbital Traversal Layer defines **how a user moves through NDH conceptual space** once inside the Safety Envelope.  
It governs:

- entry validation  
- orbit selection  
- depth modulation  
- pacing  
- guardian interventions  
- safe exits  

It is the movement layer that complements the Safety Envelope’s boundary layer.

## **3 — Entry Gate**
The Entry Gate ensures traversal begins safely.

It performs:

- **Safety Envelope compliance check**  
- **intent classification**  
- **emotional load assessment**  
- **boundary validation**

If traversal is unsafe, the Entry Gate:

- redirects to a gentler orbit  
- slows pacing  
- reframes the request  
- invokes a guardian  

---

## **4 — Orbital Path Selector**
The user enters one of three conceptual orbits:

### **4.1 — Shallow Orbit (Overview)**  
- minimal cognitive load  
- broad framing  
- no recursion  
- no deep jumps  

### **4.2 — Medium Orbit (Details)**  
- structured explanation  
- controlled recursion  
- pacing enforced  

### **4.3 — Deep Orbit (Technical / Architectural)**  
- high detail  
- recursion allowed with guardian presence  
- strict pacing  
- mandatory soft‑exit path  

ASCII representation:

```text
           Deep Orbit
         (High Detail)
              O
           /     \
         /         \
Shallow O-----------O Medium
Orbit                 Orbit
(Overview)         (Details)
```

---

## **5 — Depth & Pace Controller**
This subsystem regulates:

- how far the user goes  
- how fast traversal proceeds  
- how many conceptual jumps occur  
- whether recursion is allowed  

Rules:

- no sudden depth jumps  
- no multi‑orbit jumps without pause  
- recursion requires guardian presence  
- pacing must remain gentle  

ASCII:

```text
Depth:   [Shallow] -> [Medium] -> [Deep]
Pace:    Slow ---- Controlled ---- Slow
```

---

## **6 — Guardian Interventions**
Guardians (Sneks) provide trauma‑informed safety.

They may:

- warn softly  
- redirect gently  
- illuminate safer paths  
- slow traversal  
- block unsafe recursion  

They never:

- punish  
- shame  
- overwhelm  
- force  

ASCII:

```text
      +-----------+
      |  Snek 🐍   |
      | Guardian   |
      +-----------+
           |
           v
   Warn → Redirect → Soften
```

---

## **7 — Exit / Soft Landing**
Every traversal ends with:

- a calm summary  
- a gentle deceleration  
- a clear next step  
- no abrupt termination

```text
|  Next Gentle Step Offered |
+---------------------------+
```
