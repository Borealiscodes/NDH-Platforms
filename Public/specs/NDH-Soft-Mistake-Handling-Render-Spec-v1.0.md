# **🎨 NDH Render Spec — Soft Mistake Handling PNG v1.0**  
### *NDH‑Platforms → Public → specs*

A trauma‑informed rendering specification defining how the **Soft Mistake Handling PNG** must be constructed, governed, and integrated into the NDH public expressive layer.

This PNG represents **Coil’s gentle redirect**, used when a public user makes a small mistake, enters an unclear query, or drifts toward an emotionally unsafe path.

---

## **1 — Purpose & Ontology Binding**

### **Purpose**
The Soft Mistake Handling PNG visually communicates:

> “It’s okay — let’s gently guide you toward a clearer path.”

It must show **Coil** performing a soft redirect, without:

- urgency  
- correction  
- evaluation  
- escalation  

### **Ontology Bindings**
- **Guardian Roles** — Coil (Redirect)  
- **Safety Envelope** — soft boundary  
- **Traversal Node: Reversibility** — gentle backtracking  
- **Public Query Node** — user intent clarification  

---

## **2 — Canvas Specification**

### **Canvas Size**
- **1400 × 900 px**  
- Transparent background  
- Landscape orientation  

### **Canvas Zones**
- **Left Zone:** User intent (unclear or ambiguous)  
- **Center Zone:** Soft boundary  
- **Right Zone:** Clearer path  

The PNG must visually imply *support*, not *correction*.

---

## **3 — Palette Specification**

### **Primary Colors (NDH Pastel Set)**
- Gentle Mint (#D9F5E5) — user intent  
- Soft Lavender (#CFC7FF) — safety boundary  
- Warm Peach (#FFD8C8) — Coil  
- Mist Blue (#CDE7FF) — clearer path  

### **Rules**
- No saturated colors  
- No red or warning tones  
- No high‑contrast edges  
- No neon or urgency cues  

Palette must follow **Blueprint Suite v1.0**.

---

## **4 — Geometry Specification**

### **Shapes**
- Rounded rectangles (20–30 px radius)  
- Soft arcs (Bezier curves)  
- No sharp corners  
- No straight arrows  

### **Redirect Arc**
- A single gentle arc from “unclear intent” → “clearer path”  
- Must be curved, soft, and reversible  
- Opacity: 70–85%  
- Line weight: 4–6 px  

### **Coil Placement**
- Coil sits *near* the arc, not on top of it  
- Posture: leaning slightly toward the clearer path  
- Expression: neutral, supportive, non‑evaluative  

---

## **5 — Trauma‑Informed Constraints**

### **Required**
- No urgency cues  
- No “error” symbolism  
- No red X, warning triangles, or exclamation marks  
- No sharp arrowheads  
- No rigid geometry  
- No forced movement  
- No implication of “wrongness”  

### **Emotional Tone**
- Gentle  
- Reassuring  
- Non‑judgmental  
- Calm  
- Reversible  

### **Guardian Posture**
- Coil must appear supportive  
- Redirect posture must be soft, not corrective  
- No pointing gestures  
- No evaluative expressions  

---

## **6 — Layout Specification**

### **Left Zone — Unclear Intent**
- Rounded shape  
- Gentle mint palette  
- Label: “Unclear Intent”  
- Optional tiny snek silhouette or neutral icon  

### **Center Zone — Soft Boundary**
- Soft lavender boundary  
- Slight glow (10–15% opacity)  
- Represents emotional safety  

### **Right Zone — Clearer Path**
- Mist blue shape  
- Label: “Clearer Path”  
- Must look calm and approachable  

### **Redirect Arc**
- Gentle curve from left → right  
- Coil positioned near the midpoint  
- Arc must visually imply “soft guidance”  

---

## **7 — Labeling Specification**

### **Required Labels**
- “Unclear Intent”  
- “Soft Redirect”  
- “Clearer Path”  

### **Font**
- Rounded sans‑serif  
- 24–32 px  
- Soft gray (#6A6A6A)  
- No bold  
- No italics  

### **Placement**
- Centered  
- Never touching edges  
- Never overlapping arcs  

---

## **8 — Reversibility Specification**

The PNG must visually imply:

- The user can return to the original intent  
- Coil supports reversibility  
- The redirect is optional  
- The clearer path is a suggestion, not a correction  

Reversibility is a **core NDH trauma‑informed invariant**.

---

## **9 — Integration Rules**

### **Public UX**
- Used when a user enters an unclear query  
- Used in onboarding  
- Used in public documentation  

### **Blueprint Suite**
- Must follow palette, geometry, trauma‑informed rules  

### **PNG Integration Blueprint**
- Must bind to guardian roles  
- Must bind to safety envelope semantics  
- Must bind to public query nodes  

### **ASCII/SVG Alignment**
- ASCII remains canonical  
- SVG remains structural  
- PNG remains expressive
