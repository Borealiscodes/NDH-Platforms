# **🟣 NDH Trans‑Orbital Flow PNG Description v1.0**  
### *Canonical rendering specification for `trans-orbital-flow.png`*

---

## 🟢 **Trans‑Orbital Flow Overview**  
### **Filename**  
```
docs/public/img/trans-orbital-flow.png
```

### **Purpose**  
Shows the **full traversal pipeline**, from user intent → safe entry → orbit selection → depth/pace → guardian intervention → soft exit.

This PNG is the **linear, emotionally‑safe map** of how traversal works.

It must feel:

- calm  
- predictable  
- non‑urgent  
- non‑directive  
- gently guiding  

---

## 🟢 **Canvas Geometry**  
- **Size:** 2000 × 1200 px  
- **Background:** white (#FFFFFF)  
- **Style:** low‑stimulus, no texture, no noise  
- **Layout:** left → right linear flow  

This canvas is intentionally wide to support a gentle, readable pipeline.

---

## 🟢 **Node Geometry**  
Six rounded nodes, evenly spaced:

1. **User Intent**  
2. **Entry Gate**  
3. **Orbital Selector**  
4. **Depth & Pace Controller**  
5. **Guardian Intervention**  
6. **Soft Exit**

### Node Style  
- Shape: rounded rectangle  
- Fill: soft pastel gradient (#F7F4FF → #E8F8FF)  
- Stroke: 3px soft gray (#D0D0D0)  
- Glow: 8px blur, 20% opacity  
- Corners: fully rounded  

Nodes must feel gentle and non‑directive.

---

## 🟢 **Arrows**  
Arrows show **forward movement only**.

### Arrow Rules  
- Rounded arrowheads  
- Stroke: 3px  
- Color: soft gray (#BFBFBF)  
- No branching  
- No recursion  
- No urgency cues  
- No red  

Arrows must be soft, curved slightly, and emotionally neutral.

---

## 🟢 **Guardian Snek**  
A tiny Snek appears near the **Guardian Intervention** node.

### Snek Rules  
- Style: Kawaii, gentle  
- Color: soft purple (#BFA9FF)  
- Posture: curled or guiding  
- Emotion: supportive, not corrective  
- Placement: right side of the node, not blocking flow  

Sneks must be optional but recommended.

---

## 🟢 **Labels**  
Each node must include a label:

- “User Intent”  
- “Entry Gate”  
- “Orbital Selector”  
- “Depth & Pace Controller”  
- “Guardian Intervention”  
- “Soft Exit”

### Typography  
- Font: Inter Rounded  
- Color: #555555  
- Weight: Regular  
- No bold  
- No uppercase  
- Placement: centered within each node

- no sharp edges

- no urgency cues

- no clutter

The overall tone must be:

- calm
