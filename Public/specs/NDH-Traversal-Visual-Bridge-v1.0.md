# **NDH Traversal Visual Bridge Document v1.0**  
### *Connecting the Trans‑Orbital Traversal Layer to the PNG Asset Plan*

---

## **1 — Purpose of This Bridge Document**
The Trans‑Orbital Traversal Layer defines **how users move** through NDH conceptual space.  
The PNG Asset Plan defines **how that movement is gently visualized** in the public UX layer.

This bridge document explains:

- why traversal needs PNGs,  
- which traversal concepts require visual support,  
- how PNGs complement ASCII and SVG diagrams,  
- how trauma‑informed design shapes the PNG set,  
- and how the PNG plan stays minimal and non‑overwhelming.

This ensures the PNG plan is grounded in traversal logic rather than feeling like an arbitrary asset explosion.

---

## **2 — The Three Visual Layers of NDH**
Traversal visuals exist inside a **three‑layer NDH rendering pipeline**:

### **2.1 — ASCII (Canonical Layer)**  
- Defines structure  
- Used in specs  
- Low stimulus  
- No color, no metaphor  

### **2.2 — SVG (Structural Layer)**  
- Defines geometry  
- Used in UX docs  
- Arrows, rings, recursion maps  
- No expressive metaphors  

### **2.3 — PNG (Expressive Layer)**  
- Defines gentle emotional cues  
- Used in public UX  
- Sneks, envelopes, soft flows  
- Trauma‑informed pacing  

This bridge document clarifies that **PNG assets are not replacements** for ASCII or SVG — they are **complements** that support emotional safety and clarity.

---

## **3 — Why Traversal Needs PNGs**
Traversal involves:

- boundaries,  
- movement,  
- pacing,  
- guardians,  
- soft exits.

These concepts benefit from **gentle expressive visuals** because:

- movement is easier to understand when shown,  
- guardians are emotionally safer when visualized softly,  
- boundaries feel clearer when drawn,  
- pacing feels calmer when represented visually,  
- soft exits feel more intuitive when illustrated.

PNG assets provide **emotional grounding**, not structural meaning.

ASCII = meaning  
SVG = structure  
PNG = emotional safety

---

## **4 — Which Traversal Concepts Require PNG Support**
Traversal has **four core primitives** that benefit from PNG visualization:

### **4.1 — Safety Envelope**  
Users must see the boundary they are inside.

### **4.2 — Orbital Geometry**  
Users must see the rings they move between.

### **4.3 — Guardian Roles**  
Users must see the gentle interventions.

### **4.4 — Traversal Flow**  
Users must see the movement pipeline.

These four primitives map directly to the **minimal traversal PNG set**.

---

## **5 — Relationship to the Public PNG Illustration Plan**
The Public Layer already has **five PNGs**:

- Safety Envelope Overview  
- Guardian Roles  
- Habitat Map  
- Public Interaction Flow  
- Soft Mistake Handling  

Traversal PNGs **do not replace** these — they **extend** them.

### Overlap is intentional:

| Concept | Public PNG | Traversal PNG | Notes |
|--------|------------|---------------|-------|
| Safety Envelope | ✔️ | ✔️ | Shared |
| Guardian Roles | ✔️ | ✔️ | Shared |
| Habitat Map | ✔️ | ❌ | Public‑only |
| Public Interaction Flow | ✔️ | ❌ | Public‑only |
| Soft Mistake Handling | ✔️ | ❌ | Public‑only |
| Orbital Rings | ❌ | ✔️ | Traversal‑only |
| Traversal Flow | ❌ | ✔️ | Traversal‑only |

This bridge document clarifies that **Traversal PNGs are a small, focused extension**, not a second full PNG ecosystem.

---

## **6 — Trauma‑Informed Constraints**
Traversal PNGs must:

- be gentle,  
- be low‑stimulus,  
- reuse existing Kawaii Sneks,  
- avoid sharp angles,  
- avoid high contrast,  
- avoid emotional overload,  
- avoid animation,  
- avoid metaphor drift.

This keeps the PNG set **safe**, **minimal**, and **NDH‑aligned**.

---

## **7 — Why the PNG Set Is Small**
Traversal PNGs are limited to **four assets** because:

- ASCII diagrams already define structure,  
- SVG diagrams already define geometry,  
- PNGs only need to provide emotional grounding.

This bridge document ensures you understand **why the PNG set is small**, and **why it must stay small**.

---

## **8 — Summary**
This bridge document establishes:

- the role of PNGs in traversal,  
- the relationship between ASCII, SVG, and PNG layers,  
- the minimal set of traversal PNGs,  
- the complementarity with the Public PNG plan,  
- and the trauma‑informed constraints that keep the system safe.

With this bridge in place, the **Traversal PNG Asset Plan** can now be generated cleanly and confidently.
