# **NDH Traversal PNG Asset Plan v1.0**  
### *Minimal Trauma‑Informed PNG Set for Trans‑Orbital Traversal*

---

## **1 — Purpose**
This plan defines the **four PNG assets** required to visually support the Trans‑Orbital Traversal Layer in the NDH Public UX.

These PNGs:

- provide gentle emotional grounding,  
- complement ASCII (canonical) and SVG (structural) diagrams,  
- reuse existing Kawaii Snek expressive ontology,  
- remain minimal and non‑overwhelming,  
- follow trauma‑informed design constraints.

This is the **official traversal PNG set**.

---

## **2 — Design Principles**
Traversal PNGs must:

- use soft colors and rounded shapes,  
- avoid sharp angles or high contrast,  
- reuse existing Kawaii Sneks where possible,  
- avoid animation or flashing,  
- remain low‑stimulus and emotionally safe,  
- avoid metaphor drift,  
- remain consistent across versions.

PNG assets **support** traversal; they do **not define** traversal.  
ASCII remains canonical.

## **4 — Placement Rules**

All traversal PNGs must live under:

```
docs/public/img/
```

PNG filenames must:

- be lowercase,  
- use hyphens,  
- remain stable across versions,  
- avoid emotional or ambiguous naming.

---

## **5 — Rendering Constraints**

PNG assets:

- **may be embedded** in UX docs,  
- **must be referenced** in specs,  
- **must not** appear in case studies,  
- **must not** replace ASCII diagrams,  
- **must not** carry essential meaning.

PNG = emotional grounding  
SVG = structural geometry  
ASCII = canonical logic
