# **🎨 NDH Render Spec — Public Interaction Flow PNG v1.0**  
### *NDH‑Platforms → Public → specs*

A trauma‑informed rendering specification defining how the **Public Interaction Flow PNG** must be constructed, governed, and integrated into the NDH public expressive layer.

This PNG represents the **public‑facing traversal flow**, distinct from the deeper orbital traversal model.

---

## **1 — Purpose & Ontology Binding**

### **Purpose**
The Public Interaction Flow PNG illustrates how a *public user* gently moves through NDH:

User → Safety Envelope → Ontology → Guardians → Response

It is the **public‑layer counterpart** to the Trans‑Orbital Flow PNG.

### **Ontology Bindings**
- **Safety Envelope**  
- **Public Query Node**  
- **Ontology Surface**  
- **Guardian Roles**  
- **Response Manifold**  

---

## **2 — Canvas Specification**

### **Canvas Size**
- **1600 × 900 px**  
- Landscape orientation  
- Transparent background (required)

### **Canvas Zones**
- **Left Zone:** User  
- **Center Zone:** Safety Envelope  
- **Right Zone:** Ontology → Guardians → Response  

Zones must be visually balanced and emotionally neutral.

---

## **3 — Palette Specification**

### **Primary Colors (NDH Pastel Set)**
- Soft Lavender (#CFC7FF) — safety  
- Mist Blue (#CDE7FF) — ontology  
- Warm Peach (#FFD8C8) — guardians  
- Gentle Mint (#D9F5E5) — user intent  
- Cloud White (#FFFFFF) — response clarity  

### **Rules**
- No saturated colors  
- No high‑contrast edges  
- No urgency cues  
- No red, neon, or warning palettes  

Palette must remain consistent with **Blueprint Suite v1.0**.

---

## **4 — Geometry Specification**

### **Shapes**
- Rounded rectangles (20–30 px radius)  
- Soft arcs (Bezier curves)  
- No sharp corners  
- No straight arrows (must be curved)

### **Flow Arcs**
- **Arc 1:** User → Safety Envelope  
- **Arc 2:** Safety Envelope → Ontology  
- **Arc 3:** Ontology → Guardians  
- **Arc 4:** Guardians → Response  

All arcs must be gentle, curved, and reversible.

### **Line Weight**
- 4–6 px  
- Soft opacity (70–85%)

---

## **5 — Trauma‑Informed Constraints**

### **Required**
- No urgency cues  
- No sharp arrowheads  
- No forced depth traversal  
- No “danger” colors  
- No rigid geometry  
- No overwhelming density  
- No metaphor drift  

### **Emotional Tone**
- Calm  
- Reversible  
- Non‑absorptive  
- Gentle  
- Predictable  

### **Guardian Posture**
- Whisper: subtle warn  
- Coil: soft redirect  
- Lantern: warm soften  

Guardians must appear **supportive**, not evaluative.

---

## **6 — Layout Specification**

### **Left Zone — User**
- Small rounded shape  
- Gentle mint palette  
- Neutral icon or tiny snek silhouette  
- No facial expressions  

### **Center Zone — Safety Envelope**
- Large rounded boundary  
- Soft lavender palette  
- Slight glow (10–15% opacity)  
- Must visually “welcome” the user  

### **Right Zone — Ontology + Guardians + Response**
- Ontology node: Mist Blue  
- Guardian cluster: Warm Peach  
- Response node: Cloud White  

### **Flow**
- Must visually show **entry → grounding → support → output**  
- Must not imply depth escalation  
- Must not imply complexity  

---

## **7 — Labeling Specification**

### **Required Labels**
- “User”  
- “Safety Envelope”  
- “Ontology”  
- “Guardians”  
- “Response”  

### **Font**
- Rounded sans‑serif  
- 24–32 px  
- Soft gray (#6A6A6A)  
- No bold  
- No italics  

### **Label Placement**
- Centered within each shape  
- Never touching edges  
- Never overlapping arcs  

---

## **8 — Reversibility Specification**

The PNG must visually imply:

- The user can step back at any time  
- Guardians support reversibility  
- Safety Envelope is permeable, not restrictive  
- Ontology is a surface, not a tunnel  
- Response is a soft landing, not a terminal state  

Reversibility is a **core NDH trauma‑informed invariant**.

---

## **9 — Integration Rules**

### **Public UX**
- Used in onboarding  
- Used in public documentation  
- Used in NDH Search Engine Ontology pages  

### **Blueprint Suite**
- Must follow palette, geometry, and trauma‑informed rules  

### **PNG Integration Blueprint**
- Must bind to ontology nodes  
- Must bind to guardian roles  
- Must bind to safety envelope semantics  

### **ASCII/SVG Alignment**
- ASCII remains canonical  
- SVG remains structural  
- PNG remains expressive
