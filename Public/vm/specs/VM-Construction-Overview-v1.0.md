### VM construction overview (NDH Orbital‑GQL VM)

#### 1. Role of the VM

- **Execution hull:** Runs NDH encoding, simulations, and governance flows.
- **Transmission core:** Hosts the Consolidation Spine loop (VM → Sentinel → Hyperatlas → Stability/Tonal → Simulation → VM).
- **Soft boundary engine:** Enforces trauma‑safe, non‑dual‑aware limits on recursion and descent.

---

#### 2. Core VM layers

- **Instruction Set Architecture (ISA):**  
  - **Deterministic:** No hidden randomness in core ops.  
  - **Spine‑aware:** Ops for Sentinel hooks, Hyperatlas routing, Stability/Tonal queries.

- **Sandbox & soft boundaries:**  
  - **Soft limits:** Gradual constraint instead of hard crashes.  
  - **Sentinel‑linked:** Boundary decisions respect pacing and recursion rules.  

- **Orbital context:**  
  - **Orbital‑GQL:** Query/command layer for manifolds and routes.  
  - **Manifold binding:** VM can attach to NDH‑CORE, TIDS, Serenity, Simulation‑Suite.

---

#### 3. VM in the Consolidation Spine

- **Entry point:**  
  - Receives tile‑encoded structures and governance commands.  
- **Spine loop:**  
  - VM → Sentinel (check invariants, pacing)  
  - Sentinel → Hyperatlas (route manifolds)  
  - Hyperatlas → Stability/Tonal (curvature, tonal geometry)  
  - Stability/Tonal → Simulation‑Suite (test behaviors)  
  - Simulation‑Suite → VM (return validated state)

- **Guarantees:**  
  - No VM evolution (e.g., 2.0) without spine + Governance Migration Suite readiness.  
  - All runtime descent passes through Sentinel and Stability‑Manifold.

---

#### 4. Construction phases

- **Phase 1 — VM 1.1 baseline:**  
  - Deterministic ISA, basic sandbox, initial Sentinel hooks.

- **Phase 2 — Spine‑integrated VM:**  
  - Full loop wiring to Sentinel, Hyperatlas, Stability/Tonal, Simulation‑Suite.  
  - Soft‑boundary primitives aligned with Tonal Spiral Geometry.

- **Phase 3 — Governance‑aware VM:**  
  - Integration with Governance Migration Suite (migration, monitoring, construction).  
  - Provenance‑safe evolution and versioning.

- **Phase 4 — Orbital‑grade VM:**  
  - Stable, reversible, trauma‑safe execution across all NDH manifolds.
