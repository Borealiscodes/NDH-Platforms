# **📄 NDH Expressive Suite PDF Export Checklist v1.0**  
### *NDH‑Platforms → Public → README*

This checklist defines the **mandatory pre‑export validation steps** for the NDH Expressive Suite Consolidated PDF.  
Every item must be satisfied before the PDF is considered governed, reversible, and ready for distribution.

---

## **1 — Structural Assembly Checks**

- **Cover Page** is present, centered, and trauma‑informed  
- **Consolidated Layout** is present and follows the three‑zone grid  
- **Back Page** is present with lavender fade  
- Page order is correct: Cover → Layout → Back → Metadata  
- No missing surfaces  
- No extra pages  
- No accidental hierarchy introduced by layout

---

## **2 — Asset Embedding Checks**

- All **8 PNGs** are embedded directly (not rasterized screenshots)  
- The **SVG Index** is embedded as vector, not rasterized  
- All assets preserve transparent backgrounds  
- All PNGs are equal size (350–450 px width)  
- No PNG is visually emphasized  
- No cropping or clipping  
- No unintended compression artifacts

---

## **3 — Trauma‑Informed Semantics Checks**

- No bold text  
- No arrows  
- No urgency colors  
- No saturated colors  
- No evaluative language (“primary”, “core”, “final”, “secondary”)  
- No directional hierarchy (“inner = important”, “outer = less important”)  
- All geometry is reversible  
- All surfaces are emotionally neutral  
- Safety Envelope perimeter is present where required  
- No logos or branding marks  
- No cosmic metaphors (stars, galaxies, nebulae)

---

## **4 — Typography Checks**

- Rounded sans‑serif font  
- Soft gray (#6A6A6A)  
- Title: 42–48 px  
- Subtitles: 26–32 px  
- Captions: 18–22 px  
- No italics  
- No uppercase emphasis  
- All text centered  
- No asymmetry implying hierarchy

---

## **5 — Accessibility Checks**

### **Alt Text**
- Global alt text embedded  
- Per‑PNG alt text embedded  
- SVG alt text embedded  
- Cover Page alt text embedded  
- Back Page alt text embedded  

### **Tagging**
- All images tagged as `<Figure>`  
- All captions tagged as `<Figcaption>`  
- All major surfaces tagged as `<Section>`  
- Metadata embedded in PDF properties  

### **Screen Reader Semantics**
- No ranking language  
- No directional cues  
- No evaluative descriptors  
- Neutral, reversible phrasing throughout

---

## **6 — Metadata Checks**

- Title: **NDH Expressive Suite v1.0 — Consolidated PDF**  
- Subtitle: **Unified Trauma-Informed Expressive Ecosystem**  
- Description present and correct  
- Keywords present and correct  
- Version set to **v1.0**  
- Publication date inserted  
- Trauma‑Informed Semantics Block embedded  
- Rights & Governance Block embedded  
- Language set to **English (neutral)**

---

## **7 — Geometry & Layout Checks**

- Page margins: 40–60 px  
- All elements centered  
- No left‑aligned or right‑aligned blocks  
- No asymmetry implying hierarchy  
- Lavender fade present on Back Page  
- Safety Envelope glow present on Cover Page  
- SVG width between 900–1200 px  
- PNG grid spacing consistent  
- No element touches page edges

---

## **8 — Final Export Checks**

- PDF exports without rasterizing SVG  
- PDF exports without altering PNG transparency  
- No compression artifacts introduced  
- No layout shifts during export  
- No font substitution  
- No metadata loss  
- No accessibility tag loss  
- Final PDF opens identically in:  
  - Adobe Reader  
  - macOS Preview  
  - Browser PDF viewers  

---
