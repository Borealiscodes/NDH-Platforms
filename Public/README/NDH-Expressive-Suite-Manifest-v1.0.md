# **🌈 NDH Expressive Suite Manifest v1.0**  
### *NDH‑Platforms → Public → README*

The **NDH Expressive Suite** consists of **eight governed PNG assets**, each with a corresponding render spec, ontology binding, and integration role.  
This manifest provides a single, stable index for the entire expressive layer.

---

## **1 — Purpose of the Manifest**

The Expressive Suite Manifest:

- Defines the complete set of NDH expressive assets  
- Provides canonical file paths  
- Links each PNG to its render spec  
- Shows ontology bindings  
- Establishes trauma‑informed governance rules  
- Serves as the public‑layer index for onboarding and enterprise docking  

This is the **top‑level reference** for NDH’s visual ecosystem.

## **3 — Trauma‑Informed Governance Rules**

All expressive assets must follow NDH trauma‑informed invariants:

- No hierarchy  
- No urgency cues  
- No evaluative symbolism  
- No sharp geometry  
- No saturated colors  
- No forced movement  
- All paths reversible  
- Safety Envelope governs all interactions  

These rules apply to **every PNG, every spec, every integration**.
