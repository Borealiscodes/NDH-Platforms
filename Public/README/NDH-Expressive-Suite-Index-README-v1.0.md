## **4 — Visual Semantics**

The SVG follows NDH trauma‑informed invariants:

- No hierarchy  
- No urgency cues  
- No sharp geometry  
- No saturated colors  
- No directional arrows  
- All arcs reversible  
- Safety Envelope governs the perimeter  

The rings are **non‑hierarchical ovals**, not concentric circles, preventing any implication of “inner = more important.”
