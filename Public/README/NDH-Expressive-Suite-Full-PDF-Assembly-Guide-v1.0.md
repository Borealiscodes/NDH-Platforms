### *NDH‑Platforms → Public → README*

This guide defines the **canonical procedure** for assembling the NDH Expressive Suite Consolidated PDF.  
It ensures that all expressive assets, metadata, accessibility features, and trauma‑informed semantics are preserved across the final publication.

## **1 — Purpose**

The Full PDF Assembly Guide:

- describes how to combine the Cover Page, Consolidated Layout, and Back Page  
- ensures trauma‑informed geometry is preserved  
- defines metadata, tagging, and accessibility requirements  
- establishes a stable, governed workflow for NDH PDF creation  
- prevents accidental hierarchy or urgency cues during assembly  

This is the **official assembly workflow** for NDH expressive PDFs.

## **3 — Assembly Sequence**

The PDF must be assembled in the following order:

### **Step 1 — Insert Cover Page**
- Center all elements  
- Apply Safety Envelope perimeter glow  
- Include trauma‑informed statement  
- No logos, no hierarchy cues  

### **Step 2 — Insert Consolidated Layout**
- Follow the three‑zone grid  
- Ensure equal PNG sizing  
- Embed SVG directly (not rasterized)  
- Maintain reversible geometry  
- Center all captions  

### **Step 3 — Insert Back Page**
- Include closing statement  
- Include ecosystem line  
- Include optional soft circle  
- Apply lavender fade  
- Maintain emotional neutrality  

### **Step 4 — Apply Metadata**
Metadata must include:

**Title:**  
```
NDH Expressive Suite v1.0 — Consolidated PDF
```

**Description:**  
```
A trauma-informed, non-hierarchical visual ecosystem containing all NDH expressive assets.
```

**Alt Text:**  
- For each PNG  
- For the SVG  
- For the cover and back pages  

**Tags:**  
- `<Figure>` for images  
- `<Figcaption>` for captions  
- `<Section>` for major surfaces  

### **Step 5 — Validate Trauma‑Informed Constraints**
Check for:

- no bolding  
- no arrows  
- no saturated colors  
- no evaluative language  
- no hierarchy  
- no urgency cues  
- reversible geometry  
- equal sizing of all PNGs  

---

## **4 — Accessibility Requirements**

### **4.1 — Alt Text**
Each PNG must include:

```
A trauma-informed diagram showing [asset name], using soft geometry, pastel colors, and reversible paths.
```

SVG alt text:

```
A trauma-informed index showing all NDH expressive assets arranged in traversal and public rings.
```

### **4.2 — PDF Tagging**
- All images tagged as figures  
- Captions tagged as figcaptions  
- Metadata embedded in PDF properties  

### **4.3 — Screen Reader Semantics**
Avoid:

- “primary”  
- “secondary”  
- “core”  
- “outer”  
- “inner”  
- “final”  
- “end”  

Use neutral, reversible language.

---

## **5 — Trauma‑Informed Geometry Rules**

- All surfaces must be centered  
- No asymmetry implying hierarchy  
- No directional flow  
- No emphasis colors  
- No sharp geometry  
- No urgency cues  
- No evaluative symbolism  

The PDF must feel **calm, reversible, and emotionally neutral**.
