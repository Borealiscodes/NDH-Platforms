# **📄 NDH Expressive Suite Consolidated PDF README v1.0**  
### *NDH‑Platforms → Public → README*

The **Expressive Suite Consolidated PDF** presents all eight NDH expressive assets and the Expressive Suite Index SVG together on a single governed PDF surface.  
This README explains the purpose, structure, and trauma‑informed semantics of that consolidated layout.

---

## **1 — Purpose**

The consolidated PDF provides:

- a **single‑surface overview** of the entire expressive suite  
- a **stable onboarding artifact** for new contributors  
- a **governed reference** for enterprise docking  
- a **visual index** aligned with NDH ontology bindings  
- a **non‑hierarchical presentation** of traversal, public, and activation layers  

It is the **top‑level PDF representation** of NDH’s expressive ecosystem.

---

## **2 — Included Assets**

The consolidated PDF contains:

- **8 PNGs**  
  - Safety Envelope  
  - Orbital Rings  
  - Guardian Roles  
  - Trans‑Orbital Flow  
  - Public Interaction Flow  
  - Soft Mistake Handling  
  - Habitat Map  
  - Constellation Activation  

- **1 SVG**  
  - NDH Expressive Suite Index v1.0  

All assets must be embedded directly, not rasterized.

---

## **3 — Layout Structure**

The PDF uses a **three‑zone trauma‑informed grid**:

### **Zone A — Expressive Suite Index SVG**
- Centered  
- 900–1200 px width  
- Caption:  
  *NDH Expressive Suite Index v1.0 — governed, reversible, non-hierarchical*

### **Zone B — Traversal Ring PNGs**
- 2×2 grid  
- Equal spacing  
- No implied ordering  
- Neutral captions  

### **Zone C — Public Ring + Activation PNGs**
- 2×2 grid  
- Activation PNG treated as equal, not central  
- Neutral captions  

This structure ensures **non‑hierarchical geometry** and **reversible interpretation**.

---

## **4 — Trauma‑Informed Semantics**

The consolidated PDF must:

- avoid hierarchy  
- avoid urgency cues  
- avoid directional arrows  
- avoid saturated colors  
- avoid evaluative language  
- preserve reversible paths  
- maintain equal sizing of all PNGs  
- present activation as *part of* the constellation, not above it  

These rules ensure emotional safety and conceptual neutrality.

---

## **5 — Accessibility Requirements**

### **Alt Text**
Each PNG must include alt text describing:

```
A trauma-informed diagram showing [asset name], using soft geometry, pastel colors, and reversible paths.
```

The SVG must include:

```
A trauma-informed index showing all NDH expressive assets arranged in traversal and public rings.
```

### **PDF Tagging**
- PNGs → `<Figure>`  
- Captions → `<Figcaption>`  
- SVG → `<Figure>`  
- Alt text embedded in metadata  

### **Screen Reader Semantics**
- No ranking language  
- No “primary/secondary” terminology  
- No directional or evaluative cues
