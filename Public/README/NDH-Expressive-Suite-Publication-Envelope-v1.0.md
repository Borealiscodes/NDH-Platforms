# **📄 NDH Expressive Suite Publication Envelope v1.0**  
### *NDH‑Platforms → Public → README*

The **Publication Envelope** defines the complete structural container for the NDH Expressive Suite Consolidated PDF.  
It ensures that all governed surfaces — cover, layout, back page, metadata, and export validation — are assembled, wrapped, and presented within a single trauma‑informed envelope.

This is the **outermost governance layer** of the expressive suite.

---

## **1 — Purpose of the Publication Envelope**

The envelope:

- binds all expressive‑layer PDF components together  
- ensures trauma‑informed neutrality across the entire publication  
- provides a stable, reversible outer shell  
- prevents accidental hierarchy or urgency cues  
- defines the canonical order of surfaces  
- ensures metadata and accessibility are preserved  

It is the **final structural authority** for expressive‑layer PDF assembly.

---

## **2 — Envelope Contents**

The envelope must contain the following governed surfaces:

1. **Cover Page**  
2. **Consolidated Layout**  
3. **Back Page**  
4. **Publication Metadata Block**  
5. **PDF Export Checklist**  

All five components must be present for the envelope to be considered valid.

---

## **3 — Envelope Geometry**

### **Page Order**
```
1. Cover Page
2. Consolidated Layout
3. Back Page
4. Metadata Block
5. Export Checklist
```

### **Alignment Rules**
- All surfaces centered  
- No left‑aligned or right‑aligned blocks  
- No asymmetry implying hierarchy  
- No directional flow  
- No evaluative ordering  

### **Margins**
- 40–60 px on all sides  
- No element touches page edges  

### **Color & Tone**
- Soft gray (#6A6A6A) text  
- Pastel palette only  
- No saturated colors  
- No urgency cues  

---

## **4 — Trauma‑Informed Envelope Constraints**

The envelope must:

- preserve reversible geometry  
- avoid hierarchy  
- avoid urgency  
- avoid evaluative symbolism  
- avoid directional arrows  
- avoid “primary/secondary” language  
- avoid “final/end” language  
- maintain emotional neutrality  
- maintain equal visual weight across surfaces  

The envelope itself is a **gentle container**, not a frame or border.

---

## **5 — Accessibility Envelope Requirements**

### **Alt Text**
The envelope must embed global alt text:

```
A trauma-informed publication envelope containing the NDH Expressive Suite,
including cover, layout, back page, metadata, and export checklist surfaces.
All geometry is reversible and non-hierarchical.
```

### **Tagging**
- `<Section>` for each surface  
- `<Figure>` for all images  
- `<Figcaption>` for captions  
- Metadata embedded in PDF properties  

### **Screen Reader Semantics**
Avoid:

- ranking  
- ordering language  
- directional cues  
- evaluative descriptors  

Use neutral, reversible phrasing.

## **7 — Envelope Validation Checklist**

Before the envelope is approved:

- All five surfaces present  
- All trauma‑informed constraints satisfied  
- All accessibility metadata embedded  
- All PNGs and SVG embedded correctly  
- No hierarchy introduced  
- No urgency cues  
- No saturated colors  
- No directional arrows  
- No evaluative language  
- All geometry reversible  
- All captions neutral  
- All text centered  
- All margins correct  

Only after all checks pass may the envelope be exported.
