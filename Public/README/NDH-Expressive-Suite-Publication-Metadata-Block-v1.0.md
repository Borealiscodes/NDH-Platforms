# **📄 NDH Expressive Suite Publication Metadata Block v1.0**  
### *NDH‑Platforms → Public → README*

The **Publication Metadata Block** defines the canonical metadata required for any NDH expressive‑layer PDF.  
It ensures accessibility, semantic clarity, trauma‑informed neutrality, and consistent identification across NDH documentation.

---

## **1 — Purpose**

This metadata block:

- standardizes expressive‑layer PDF metadata  
- ensures accessibility compliance  
- embeds trauma‑informed semantics  
- prevents accidental hierarchy or urgency cues  
- provides a stable identity for NDH expressive publications  
- supports enterprise docking and archival workflows  

This block must be included **verbatim** in every expressive‑layer PDF.

---

## **3 — Accessibility Metadata**

### **3.1 — Alt Text (Global)**
```
A trauma-informed visual ecosystem showing NDH traversal, public, and activation
layers using soft geometry, pastel colors, and reversible paths.
```

### **3.2 — Alt Text (Per Asset)**  
Each PNG must include:

```
A trauma-informed diagram showing [asset name], using soft geometry, pastel colors,
and reversible paths.
```

SVG alt text:

```
A trauma-informed index showing all NDH expressive assets arranged in traversal and
public rings.
```

### **3.3 — PDF Tagging**
- `<Figure>` for all images  
- `<Figcaption>` for all captions  
- `<Section>` for cover, layout, and back page  
- Metadata embedded in PDF properties  

### **3.4 — Screen Reader Semantics**
Avoid:

- “primary”  
- “secondary”  
- “core”  
- “outer”  
- “inner”  
- “final”  
- “end”  

Use neutral, reversible language.

## **4 — Trauma‑Informed Semantics Block**

This block must be embedded in the PDF metadata:

```
This publication follows NDH trauma-informed invariants: non-hierarchical geometry,
reversible paths, soft pastel palette, emotionally neutral semantics, and gentle
visual surfaces. No urgency cues, evaluative symbolism, or directional hierarchy
are present in any expressive asset.
```
