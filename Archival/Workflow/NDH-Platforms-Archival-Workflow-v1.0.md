# **Operator‑Tier Interpretation**

### **1. TISD Evaluates**  
Artifacts enter TISD first.  
TISD applies the rubric and decision tree.  
Linked concept: **TISD Governance**

### **2. NDH‑Platforms Stores Expressive Lineage**  
Only expressive artifacts (score ≥3) enter NDH‑Platforms.  
Linked concept: **Expressive Lineage**

### **3. NDH‑CORE Executes Runtime Operators**  
Runtime artifacts (score ≥3 runtime) go to CORE.  
Linked concept: **NDH‑CORE**

### **4. Hybrid Manifolds Are Retired**  
Hybrid artifacts are retired under GBS v12.  
Linked concept: **Omega‑IV Governance**
