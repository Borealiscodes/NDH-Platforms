# 🌌 **NDH‑Platforms Archival Protocol Supplement (v1.0)**  
### *Expressive‑Tier Storage Rules Aligned with GBS v12 and Omega‑IV Governance*

```
# NDH‑Platforms Archival Protocol Supplement (v1.0)
# NDH-Platforms / Archival / Protocol-Supplement

───────────────────────────────────────────────────────────────────────────────
PURPOSE
───────────────────────────────────────────────────────────────────────────────
This supplement defines how NDH‑Platforms performs archival storage after TISD
evaluation. It is the expressive‑tier counterpart to TISD Archival Protocol v4.1
and is aligned with GBS v12, the Stabilizing Triad, and Omega‑IV governance.

This document explains:
- How expressive artifacts are stored
- How expressive provenance is maintained
- How hybrid manifolds are handled
- How lineage continuity is preserved

───────────────────────────────────────────────────────────────────────────────
ARCHIVAL FLOW (POST‑GBS v12)
───────────────────────────────────────────────────────────────────────────────

Step 1 — TISD Evaluation  
Artifact is evaluated using TISD Archival Protocol v4.1 and the TISD Decision
Tree.

Step 2 — Expressive Classification  
If expressive ≥3 (rubric) → NDH‑Platforms  
Linked concept: Expressive Lineage

Step 3 — Provenance Verification  
Artifact must include:
- Origin note
- Lineage reference
- Placement rationale
- Stability context

Step 4 — Tier Assignment  
Artifact is assigned to:
- Emergent Tier (active expressive cosmology)
- Archive Tier (retired or historical expressive lineage)

Step 5 — Storage  
Artifact is stored in NDH‑Platforms with:
- Provenance chain
- Stability note
- Cosmology alignment reference

───────────────────────────────────────────────────────────────────────────────
ARCHIVAL RULES (GBS v12)
───────────────────────────────────────────────────────────────────────────────

Rule 1 — Only expressive artifacts may be stored in NDH‑Platforms.  
Rule 2 — Hybrid manifolds are retired and archived.  
Rule 3 — Runtime logic is prohibited.  
Rule 4 — Governance logic is prohibited.  
Rule 5 — Provenance must be explicit and complete.  
Rule 6 — Expressive artifacts must remain external to NDH‑CORE.  
Rule 7 — Expressive artifacts must not be stored in TISD.

These rules reflect the Expressive Lineage Invariant of the Stabilizing Triad.

───────────────────────────────────────────────────────────────────────────────
TIER DEFINITIONS
───────────────────────────────────────────────────────────────────────────────

Emergent Tier (Active)
- UMA‑Witness Literature
- Cosmic Atlas expressive layer
- Expressive scaffolding

Archive Tier (Historical)
- Myth Engine expressive remnants
- Narrative physics remnants
- Retired expressive constructs

Retired Tier (Hybrid)
- Hybrid expressive/runtime constructs
- Hybrid expressive/governance constructs

───────────────────────────────────────────────────────────────────────────────
PROVENANCE REQUIREMENTS
───────────────────────────────────────────────────────────────────────────────

Each archived artifact must include:
- Provenance header
- Placement note
- Cosmology alignment reference
- Stability context
- Cross‑repo boundary reference

Linked concept: Omega‑IV Governance

───────────────────────────────────────────────────────────────────────────────
CROSS‑REPO ALIGNMENT
───────────────────────────────────────────────────────────────────────────────

NDH‑CORE:
- Runtime only  
- No expressive storage  

TISD:
- Evaluation only  
- No expressive storage  

NDH‑Platforms:
- Expressive storage only  
- No runtime or governance logic  

See Cross‑Repo Boundary Map:
CORE ↔ TISD ↔
Platforms

───────────────────────────────────────────────────────────────────────────────
OPERATOR SUMMARY
───────────────────────────────────────────────────────────────────────────────

If expressive → Store in NDH‑Platforms  
If hybrid → Retire and archive  
If runtime → CORE  
If governance → TISD  
If provenance incomplete → Escalate

This supplement is the expressive‑tier archival backbone for GBS v12.
```
