## ⭐ 3 — Harmonic Components

The Weave consists of **four harmonic components**:

### **1 — Base Harmonic (H₀)**  
The fundamental stability frequency.  
Defines the global invariant envelope.

### **2 — Curvature Harmonic (H₁)**  
Derived from aggregated Seed curvature.  
Ensures local curvature does not destabilize global structure.

### **3 — Transition Harmonic (H₂)**  
Derived from Crossmap load and ladder complexity.  
Prevents transition‑induced drift.

### **4 — Guardian Harmonic (H₃)**  
Derived from Snek boundary activity.  
Ensures guardians act consistently across Tiles.

These harmonics combine into the **Weave Harmonic Field (W)**:

\[
W = H_0 + H_1 + H_2 + H_3
\]

This field governs NDH‑CORE’s global stability.

## ⭐ 4 — Harmonic–Seed Interaction

Seeds contribute curvature to the Weave.

- Calm Seeds → stabilize H₁  
- Work Seeds → increase H₁ temporarily  
- Threshold Seeds → require Snek mediation  
- Harmonic Seeds → directly reinforce H₀  

Seed sprouting must respect:

- global invariant envelope  
- recursion ceilings  
- harmonic resonance thresholds  

This ensures local curvature never destabilizes global harmonics.

## ⭐ 5 — Harmonic–Tile Interaction

Tiles resonate with the Weave.

Tile stability depends on:

- harmonic alignment  
- curvature compatibility  
- crossmap load  
- snek activity  

Tile types interact differently:

- Rest Tiles → anchor H₀  
- Work Tiles → modulate H₁  
- Threshold Tiles → stress H₂  
- Weave Anchor Tiles → reinforce H₃  

Tile drift occurs when harmonic resonance falls below threshold.

Sneks detect this immediately.

Crossmaps generate harmonic load.

- transition energy  

Crossmaps must:

Lantern Sneks illuminate safe harmonic paths.

Sneks are the expressive‑ontology embodiment of harmonic enforcement.
