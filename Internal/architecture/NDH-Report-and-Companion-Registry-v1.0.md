## ⭐ 1 — Core Report Types  
These are the **primary analytical layers** NDH uses.  
They form the backbone of NDH’s knowledge architecture.

Each item is a Guided Link so you can generate it directly.

- **Emergent Case Study**  
  - First‑order analysis of system behavior  
  - Detects emergent patterns, drift, governance phenomena  

- **Meta Analysis**  
  - Second‑order interpretation  
  - Explains why the emergent behavior exists  

- **Meta‑Meta Analysis**  
  - Third‑order reflection  
  - Places NDH behavior in conceptual, epistemic, or systemic context  

These three form the **NDH Analysis Spine**.

## ⭐ 4 — Scopes (Internal / Public / Dual)  
Every report or companion must declare its scope:

### **Internal**
- NDH manifold semantics  
- tensor/vector/holonomy mechanics  
- GQL ingestion rules  
- raw telemetry semantics  
- invariants  
- developer‑grade architecture  
- ops specifications  

### **Public**
- conceptual explanations  
- safe benchmarking  
- diagrams  
- high‑level architecture  
- accessible companions  
- ethics/philosophy framing  

### **Dual**
- some artifacts have both versions  
- internal version contains NDH mechanics  
- public version is sanitized  

This prevents leakage and drift.
