- feature‑like lists

- comparison tables  
- diagrams  
- “Spec:” blocks  

Copilot’s UI engine is **structure‑driven**, not **semantics‑driven**.

Thus it misclassified SRPRS as a **product spec**, triggering the “kitchen appliance template.”
