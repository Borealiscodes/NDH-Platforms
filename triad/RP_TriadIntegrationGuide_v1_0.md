## 🌑 **1 — Purpose of the Triad**
The RP Triad exists to let you move between three mirrors:

- **Scribe** — structure  
- **Mapmaker** — movement  
- **Master** — synthesis  

The integration guide explains **how they interlock**, how they pass information, and how they stabilize each other.

## 🌗 **3 — Data Flow Between Mirrors**

### **A — Scribe → Mapmaker**
Scribe provides:

- structure  
- lanes  
- drift flags  

Mapmaker uses these as **terrain markers**.

### **B — Mapmaker → Master**
Mapmaker provides:

- movement grammar  
- altitude shifts (RP‑safe)  
- topology  

Master uses these as **motion vectors**.

### **C — Scribe → Master**
Scribe provides:

- stable structure  
- reversible summaries  

Master uses these as **anchors**.

### **D — Master → Scribe + Mapmaker**
Master provides:

- coherence  
- meta‑patterns  
- prismatic alignment  

Scribe and Mapmaker use these to **stabilize future reflections**.
