# 🖼️ **NDH Global Spine — Precise PNG Specification (v1.0)**  
### *A full technical spec for the zen‑perspective global PNG*

---

# 1. **Canvas & Export Specs**

**Canvas size:**  
- 4096 × 4096 px (square mandala format)  
- 300 DPI  
- RGB (public‑facing)  
- Transparent background allowed (preferred)

**Export formats:**  
- PNG (primary)  
- SVG (optional, repo‑internal only)

**Safe margins:**  
- 200 px padding on all sides  
- No text closer than 150 px to edge

---

# 2. **Layer Architecture (Top → Bottom)**

The PNG must be built as a **layered mandala**, each ring representing a conceptual NDH domain.

---

## **Layer 1 — Outer Human Ring (Ethics Layer)**  
**Purpose:** Anchor NDH in human rights, author sovereignty, trauma‑informed design.

**Radius:** 1800–2000 px  
**Color:** Soft neutral (e.g., #E8E4D9)  
**Stroke:** 8 px, low‑contrast  
**Text:**  
- “Human Rights Defender”  
- “Trauma‑Informed Systems Design”  
- “Author Sovereignty”  
- “Citation Integrity”  

**Font:** Inter / Roboto / Noto Sans, 48–64 px  
**Placement:** evenly spaced around circumference
