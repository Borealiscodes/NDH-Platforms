# **🖼️ NDH PNG Integration Blueprint v1.0**  
### *NDH‑Platforms → Ontology → BlueprintSuite*

A governed, trauma‑informed integration blueprint defining how all NDH PNG assets — traversal and public — bind to ontology nodes, guardians, safety envelope semantics, rendering specs, and repo geometry.

This blueprint ensures the PNG ecosystem behaves as a **single expressive system**, not isolated assets.

---

# **1 — PNG Ecosystem Overview**

NDH contains **7 governed PNGs**, divided into two layers:

### **Traversal Layer PNGs**
- **Safety Envelope PNG**  
- **Orbital Rings PNG**  
- **Guardian Roles PNG**  
- **Trans‑Orbital Flow PNG**  

### **Public Layer PNGs**
- **Public Interaction Flow PNG**  
- **Soft Mistake Handling PNG**  
- **Habitat Map PNG**  

### **Shared Assets**
- Safety Envelope  
- Guardian Roles  

These 7 PNGs form the **complete NDH expressive layer**.

---

# **2 — Integration Principles**

### **2.1 Trauma‑Informed Visual Governance**
All PNGs must follow:

- pastel palette  
- rounded geometry  
- gentle arcs  
- reversible motion  
- non‑absorptive semantics  
- non‑hierarchical layout  
- no urgency cues  
- no sharp edges  
- no evaluative symbolism  

### **2.2 Layer Separation**
Traversal PNGs:

- represent depth  
- show orbital geometry  
- bind to traversal nodes  

Public PNGs:

- represent clarity  
- show gentle flow  
- bind to public ontology  

### **2.3 Shared Semantics**
Safety Envelope + Guardians appear in both layers, but:

- traversal versions show depth  
- public versions show emotional safety  

---

# **3 — Ontology Bindings**

Each PNG binds to specific ontology nodes.

### **Traversal Bindings**
- Safety Envelope → Safety Envelope Node  
- Orbital Rings → Depth Layer Nodes  
- Guardian Roles → Guardian Category  
- Trans‑Orbital Flow → Traversal Motion Nodes  

### **Public Bindings**
- Public Interaction Flow → Public Query Node  
- Soft Mistake Handling → Guardian Redirect Node  
- Habitat Map → Public Ontology Categories  

### **Shared Bindings**
- Guardians → Warn, Redirect, Soften  
- Safety Envelope → Entry Boundary  

---

# **4 — Guardian Role Bindings**

Guardians bind to PNGs as follows:

| Guardian | Traversal Layer | Public Layer |
|----------|-----------------|--------------|
| Whisper | Warn | Ambient warn cue |
| Coil | Redirect | Soft redirect |
| Lantern | Soften | Emotional cushioning |

Guardians must always appear:

- supportive  
- non‑evaluative  
- non‑directive  

---

# **5 — Safety Envelope Bindings**

Safety Envelope PNG binds to:

- traversal entry boundary  
- public entry boundary  
- reversibility semantics  
- emotional safety rules  

Safety Envelope must:

- glow softly  
- never imply restriction  
- never imply urgency  
- never imply depth escalation
