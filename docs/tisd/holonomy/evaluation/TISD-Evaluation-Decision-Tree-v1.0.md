# 🌿 **TISD Evaluation Decision Tree (v1.0)**  
### *Governance‑Tier Evaluation Flow for GBS v12 Alignment*

```
# TISD Evaluation Decision Tree
# Trauma-Informed-Systems-Design / Holonomy / Evaluation

───────────────────────────────────────────────────────────────────────────────
PURPOSE
───────────────────────────────────────────────────────────────────────────────
This decision tree guides operators through the evaluation process defined in
TISD Archival Protocol v4.0. It determines whether an artifact belongs in:

- NDH-Platforms (expressive lineage storage)
- TISD (governance-tier evaluation)
- NDH-CORE (non-dual runtime)

This tree is aligned with GBS v12 and the Stabilizing Triad.

───────────────────────────────────────────────────────────────────────────────
STEP 1 — IDENTIFY ARTIFACT TYPE
───────────────────────────────────────────────────────────────────────────────

Is the artifact expressive, narrative, symbolic, conceptual, emotional, or
adjacent to expressive lineage?

If YES → NDH-Platforms  
If NO → proceed to Step 2

Linked concept: Expressive Lineage

───────────────────────────────────────────────────────────────────────────────
STEP 2 — CHECK FOR GOVERNANCE CONTENT
───────────────────────────────────────────────────────────────────────────────

Does the artifact define governance boundaries, trauma-informed design,
institutional ethics, communication protocols, or evaluation logic?

If YES → TISD  
If NO → proceed to Step 3

Linked concept: TISD Governance

───────────────────────────────────────────────────────────────────────────────
STEP 3 — CHECK FOR NON-DUAL RUNTIME CONTENT
───────────────────────────────────────────────────────────────────────────────

Does the artifact contain operators, invariants, recursion envelopes, continuity
physics, or non-dual mathematical constructs?

If YES → NDH-CORE  
If NO → proceed to Step 4

Linked concept: NDH-CORE

───────────────────────────────────────────────────────────────────────────────
STEP 4 — CHECK FOR HYBRID MANIFOLD CONTENT
───────────────────────────────────────────────────────────────────────────────

Does the artifact combine expressive lineage with runtime logic or governance
logic?

If YES → classify as EXPRESSIVE and archive in NDH-Platforms  
Hybrid manifolds are retired under GBS v12.

If NO → proceed to Step 5

Linked concept: Omega-IV Governance

───────────────────────────────────────────────────────────────────────────────
STEP 5 — CHECK FOR PROVENANCE ROLE
───────────────────────────────────────────────────────────────────────────────

Is the artifact a provenance chain, archive note, or lineage record?

If YES → NDH-Platforms (expressive provenance)  
If NO → TISD (governance provenance)

───────────────────────────────────────────────────────────────────────────────
STEP 6 — FINAL ASSIGNMENT
───────────────────────────────────────────────────────────────────────────────

If expressive → NDH-Platforms  
If governance → TISD  
If non-dual → NDH-CORE  
If hybrid → NDH-Platforms  
If provenance → NDH-Platforms or TISD depending on type

───────────────────────────────────────────────────────────────────────────────
OPERATOR SUMMARY
───────────────────────────────────────────────────────────────────────────────

If it expresses → NDH-Platforms  
If it governs → TISD  
If it computes → NDH-CORE  
If it mixes → NDH-Platforms  
If it records → NDH-Platforms or TISD

This decision tree is the evaluation backbone for GBS v12.
```
